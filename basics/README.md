# basics

Everyday filesystem navigation and manipulation: printing and changing the working directory, listing files in various formats, creating and removing directories, moving and deleting files, and working with wildcards and symbolic links. These are the muscle-memory commands behind almost any Linux session.

## Notable files

| File | Description |
|---|---|
| `0-current_working_directory` | Prints the current directory with `pwd` |
| `2-bring_me_home` | Moves to the home directory with `cd ~` |
| `10-back` | Returns to the previous directory with `cd -` |
| `6-firstdirectory` / `9-firstdirdeletion` | Creates and removes a directory (`mkdir` / `rmdir`) |
| `13-symbolic_link` | Creates a symbolic link with `ln -s` |
| `14-copy_html` / `15-lets_move` | Copies/moves files matched by wildcard patterns |
| `17-tree` | Creates a nested directory tree in one call (`mkdir -p`) |

📚 See the root [CHEATSHEET.md](../CHEATSHEET.md) for the concepts used here.
